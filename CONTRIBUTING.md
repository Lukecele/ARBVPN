# Contributing to ARBVPN

We welcome contributions to optimize React Native WireGuard performance, native Android/iOS bridging, and UI connection flows.

## How to Contribute
1. Fork the repository.
2. Create a feature branch: `git checkout -b feat/your-feature`.
3. Verify that code builds locally (`npm run test` / `npm run lint`).
4. Ensure no private keys or personal server addresses are committed.
5. Submit a Pull Request with a clear description.
