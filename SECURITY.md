# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability or cryptographic flaw, please do NOT open a public GitHub issue.

Please report vulnerabilities directly via:
- **Telegram:** [Arbitrage Inception Telegram](https://t.me/ArbitrageInception)

### Critical Security Guidance
- Never commit private keys (`privateKey`, `presharedKey`) to source control.
- Ensure WireGuard server access control lists strictly restrict client IP routing.
